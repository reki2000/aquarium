# エビモデル仕様（glTF 差し替え用）

`public/assets/shrimp/cherry.glb` にファイルを置くと、起動時に自動で読み込まれ、手続き生成のプレースホルダーと置き換わります（ステータス表示が `(gltf)` になります）。
ファイルが無い場合や読み込みに失敗した場合は、手続き生成のエビで動作します。

## 形式

| 項目 | 要件 |
|---|---|
| フォーマット | glTF 2.0 バイナリ（`.glb`）。Meshopt 圧縮に対応（`gltf-transform meshopt`） |
| 向き | **+Z が頭（前）、+Y が上、+X が左**（glTF の標準的な前方向 +Z） |
| スケール | 任意。読み込み時に **Z 方向のバウンディングボックス長が 22mm** になるよう正規化されます（触角を含めると正規化長が縮むため、触角を含む場合は `TARGET_BODY_LENGTH` を調整） |
| 原点 | 任意。読み込み時に X/Z 中心・足先（最下点）が y=0 になるよう移動されます |
| 静止ポーズ | 歩脚を接地させた自然な立ち姿勢 |
| ポリゴン数目安 | 1匹 5k〜20k tris（14匹程度を同時表示） |
| マテリアル | glTF の PBR マテリアルがそのまま使われます。半透明感が欲しい場合は `KHR_materials_transmission` / `KHR_materials_volume` / `KHR_materials_clearcoat` を推奨 |

## 関節（ボーン／ノード）名

アニメーションは下記の名前のノード（スキンのボーンでも、剛体パーツの親ノードでも可）を探して動かします。
**回転はエビ空間（+Z 前 / +Y 上）で与えられ、各ボーンの静止姿勢に対する相対回転として適用される**ため、Blender のボーンロールや軸の向きは気にしなくて構いません。
各関節の**原点（ピボット）が関節の付け根**になっていることだけ守ってください。

見つからない関節は単に無視されます（例：腹肢が無いモデルでも動作します）。

| 名前 | 部位 | 親 | 動き |
|---|---|---|---|
| `body` | 頭胸甲 | ルート | 採餌時の前傾、歩行時の揺れ |
| `abdomen_1` … `abdomen_6` | 腹節（前→後の連鎖） | `body` → `abdomen_{n-1}` | 呼吸、遊泳時のうねり、旋回時の曲がり |
| `telson` | 尾節＋尾肢 | `abdomen_6` | 開閉・遊泳時の反り |
| `antenna_{L,R}_1` … `_4` | 第2触角（長い方）の連鎖 | `body` → 前の節 | 探索スイープ、旋回時の遅れ、遊泳時の後方流し |
| `antennule_{L,R}_1` … `_2` | 第1触角（短い方） | `body` → 前の節 | 速いフリック |
| `leg_{1..5}_{L,R}_{1..3}` | 胸脚 5 対 × 3 節（1=付け根） | `body` → 前の節 | 1–2 対目：ハサミ脚のツマツマ動作／3–5 対目：歩行（スイング＋リフト） |
| `pleopod_{1..5}_{L,R}` | 腹肢 5 対 | `abdomen_{1..5}` | 常時の緩いあおぎ、遊泳時の強いメタクロナル波 |

`L` はエビ自身から見て左（+X 側）です。

## Blender からの書き出し手順（例）

1. モデルの前方を -Y（Blender の前方）に合わせ、上記の名前でボーンを作ってスキニング（または各パーツを空オブジェクトの子にする）
2. `File > Export > glTF 2.0`：Format = glb、+Y Up にチェック、Animation は不要
3. 最適化（任意）：`npx @gltf-transform/cli optimize in.glb public/assets/shrimp/cherry.glb --compress meshopt --texture-compress webp`

## 入手先メモ

- Sketchfab：`cherry shrimp`、`Neocaridina`、`shrimp rigged` で検索（ライセンス確認・CC-BY はクレジット必須）
- CGTrader / TurboSquid / Fab：リグ付きの有料モデル
- 生成 AI（Hunyuan3D / TRELLIS / Meshy / Tripo）：胴体のベースには使えるが、脚と触角は作り直しが必要
